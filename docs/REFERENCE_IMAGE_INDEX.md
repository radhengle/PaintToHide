## Non-negotiable reference matching
1. Preserve the distinctive silhouettes and color/material identities listed in `ART_DIRECTION.md`.
2. Do not substitute an unrelated room theme or generic repeated furniture kit.
3. Recreate props as actual 3D meshes with correct proportions, UVs, bevels and collisions.
4. The UI/gameplay boards are interface and framing references, not room geometry.
5. Any procedural blockout is temporary and must be replaced/overlaid with authored final assets before release.
