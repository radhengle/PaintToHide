# Development Roadmap

## M0 — Project foundation
- [x] Dedicated repository and design specification.
- [x] Visual direction and reference catalogue.
- [x] Connected-world floorplan.
- [ ] Unity editor import and compile validation.

## M1 — World vertical slice
- [ ] Generate Grand Hall and one connected wing.
- [ ] Import final Grand Hall architecture/furniture assets.
- [ ] Humanoid controller, camera and mobile controls.
- [ ] Collision/navmesh and player-scale QA.

## M2 — Character and camouflage
- [ ] Production humanoid rig and animations.
- [ ] Pose library and stable capsule.
- [ ] UV painting shader, brush tools, sampling, eraser, undo/redo.
- [ ] Object reference profiles and disguise scoring.

## M3 — Match and combat
- [ ] Match phase state machine and teams.
- [ ] Blaster model, projectile, 1s cooldown, 2s splash.
- [ ] Server-verified hit and elimination.
- [ ] Reveal, results and rematch.

## M4 — Bots
- [ ] Hider slot evaluation, pose and paint selection.
- [ ] Seeker navigation and suspicion perception.
- [ ] Difficulty profiles and fairness tests.

## M5 — Online multiplayer
- [ ] Choose and document provider/hosting.
- [ ] Authoritative session/replication.
- [ ] Room IDs, invitation links and matchmaking.
- [ ] Disconnect/reconnect and two-device tests.

## M6 — Full building production
- [ ] All 25 rooms modeled/dressed against references.
- [ ] Corridors, stairs, balconies, garden, roof and basement connected.
- [ ] Per-room collision, hiding slots and navigation.
- [ ] Lighting, audio, VFX and performance optimization.

## M7 — Release
- [ ] Android device matrix and performance/thermal testing.
- [ ] Security and anti-cheat review.
- [ ] Regression suite.
- [ ] Debug and signed release APK.
- [ ] Release notes and known issues.

A milestone is complete only when implemented and tested. A successful compile is not a finished game.
